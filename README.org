#+TITLE: Personal Wordlists
#+SUBTITLE: Toolkit for fetching and building tiered wordlists & cracking rules
#+OPTIONS: toc:2 num:nil


This repository contains scripts for assembling the wordlists and rules that I
use mainly in web content discovery, DNS enumeration and password cracking.

#+begin_src sh
# 0. Clone the repository
git clone https://github.com/fuzztheplanet/wordlists.git
cd wordlists

# 1. Download every source into the current directory
./fetch.sh

# 2. Build the distilled, tiered custom lists
./gen-dns.sh            # -> ./custom/dns/
./gen-passwords.sh      # -> ./custom/passwords/
./gen-web.sh            # -> ./custom/web/

# 3. Use them
ffuf -u 'http://www.example.com/FUZZ' -w ./custom/web/2_small.txt
#+end_src

* Scripts

All scripts share the same command-line conventions:

- Every long option has a short alias (=-o=/=--outdir=, ...) and takes its
  value as either =--opt value= or =--opt=value=. A bare =--= ends option
  parsing.
- =fetch.sh= and =gen-cmdexec.sh= also accept positional arguments
  (wordlist names and payload categories); the =gen-{dns,passwords,web}.sh=
  builders take options only.
- Diagnostic output (progress, warnings, errors) goes to stderr. Only data
  is written to stdout -- the payloads from =gen-cmdexec.sh= and the
  =--list= output from =fetch.sh= -- so redirecting stdout is always safe.

** fetch.sh - download the raw sources

#+begin_example
./fetch.sh -h

Fetch popular password wordlists and cracking rules in parallel.

Usage:
  ./fetch.sh [options] [wordlist ...]

Options:
  -o, --outdir DIR   Where to place the wordlists (default: current directory)
  -f, --force        Re-download wordlists that are already present
  -l, --list         List the available wordlists and exit
  -q, --quiet        Only print warnings and errors
  -h, --help         Show this help and exit

Available wordlists: crackstation, hashcat-rules, pwdb, seclists, webenum.

With no wordlist arguments, every available target is fetched.

Examples:
  ./fetch.sh                          # everything, into $PWD
  ./fetch.sh -o /opt/wordlists        # everything, into /opt/wordlists
  ./fetch.sh seclists pwdb            # only these two
  ./fetch.sh -f hashcat-rules         # redownload just the hashcat / One Rule rules
#+end_example

** gen-dns.sh - tiered DNS subdomain lists

#+begin_example
./gen-dns.sh -h

Build tiered DNS wordlists (subdomain names)

Usage:
  ./gen-dns.sh [options]

Options:
  -o, --outdir DIR    Where to write the lists      (default: ./custom/dns)
  -w, --source DIR    Directory holding seclists/   (default: .)
  -s, --small N       Size of the small tier        (default: 5000)
  -m, --medium N      Cumulative size of medium     (default: 50000)
  -b, --big N         Cumulative size of big        (default: 500000)
  -j, --jobs N        Parallelism for sort          (default: nproc)
  -k, --keep          Keep the temporary work directory
  -h, --help          Show this help and exit

Produces four disjoint files under --outdir, each holding names NOT present
in the smaller tiers, ordered so the most commonly seen come first:

  2_small.txt    most common subdomain names       (top --small)
  3_medium.txt   the next band                      (--small .. --medium)
  4_big.txt      the next band                      (--medium .. --big)
  5_rest.txt     every remaining unique name in the corpus

It also writes one combined list, one level up from --outdir and named after
the category (custom/dns.txt with the default --outdir):

  ../dns.txt     every unique name (all tiers concatenated, common-first)
#+end_example

** gen-passwords.sh - tiered password lists

#+begin_example
./gen-passwords.sh -h

Generate tiered password wordlists from the available wordlists.

Usage:
  ./gen-passwords.sh [options]

Options:
  -o, --outdir DIR    Where to write the generated lists (default: ./custom)
  -w, --source DIR    Directory holding seclists/ and pwdb/ (default: .)
  -s, --small N       Size of the small tier   (default: 10000)
  -m, --medium N      Cumulative size of medium (default: 100000)
  -b, --big N         Cumulative size of big    (default: 1000000)
  -j, --jobs N        Parallelism for sort      (default: nproc)
  -k, --keep          Keep the temporary work directory instead of deleting it
  -h, --help          Show this help and exit

It produces four disjoint files, each containing passwords NOT present in the
smaller tiers, ordered so the most common come first:

  2_small.txt    the most common passwords            (--small)
  3_medium.txt   the next band                        (--small .. --medium)
  4_big.txt      the next band                        (--medium .. --big)
  5_rest.txt     every remaining unique password in the corpus

It also writes one combined list, one level up from --outdir and named after
the category (custom/passwords.txt with the default --outdir):

  ../passwords.txt   every unique password (all tiers concatenated,
                     common-first)
#+end_example

** gen-web.sh - tiered web-enumeration lists

#+begin_example
./gen-web.sh -h

Build tiered web-enumeration wordlists (URL paths + API endpoints) from the
downloaded SecLists set, enriched with the webenum sources fetched by
./fetch.sh (Assetnote, OneListForAll, Kiterunner).

Usage:
  ./gen-web.sh [options]

Options:
  -o, --outdir DIR    Where to write the lists      (default: ./custom/web)
  -w, --source DIR    Directory holding seclists/ (and webenum/) (default: .)
  -s, --small N       Size of the small tier        (default: 5000)
  -m, --medium N      Cumulative size of medium     (default: 30000)
  -b, --big N         Cumulative size of big        (default: 100000)
  -j, --jobs N        Parallelism for sort          (default: nproc)
  -k, --keep          Keep the temporary work directory
  -h, --help          Show this help and exit

The tiers hold both paths and API endpoints, ranked most-useful-first so the
small tiers are the most efficient to run. Produces, under --outdir:

  ./custom/web/2_small.txt          most useful paths + API endpoints    (top --small)
  ./custom/web/3_medium.txt         the next band                        (--small .. --medium)
  ./custom/web/4_big.txt            the next band                        (--medium .. --big)
  ./custom/web/5_rest.txt           every remaining unique path/endpoint in the corpus
  ./custom/web/api.txt              dedicated API endpoint list (Assetnote + Kiterunner + SecLists)
  ./custom/web/extensions.txt       file extensions for fuzzing
  ./custom/web.txt                  all the previous
#+end_example
** gen-cmdexec.sh - OS command-execution payloads

Generates command-injection PoC payloads (reverse shells, file creation,
file read) from the templates in =cmdexec/= and prints them to stdout, one
per line, so they can be redirected to a file or piped into another tool.
The =touch= / =cat= payloads are the standard non-destructive way to prove
command execution in a report (drop a marker file, read =/etc/passwd=).

The templates bundle the filter-bypass and injection tricks catalogued in
SecLists, PayloadsAllTheThings and HackTricks: alternate tools, command-name
obfuscation (quotes, backslashes, concatenation), =$IFS=/space bypass,
wildcard/glob binary paths, base64/hex/octal/rev/tr decoders, chaining
separators, quote break-outs, URL-encoded operators and Windows variants.

#+begin_example
./gen-cmdexec.sh -h

Generate OS command-execution payloads from the templates in ./cmdexec by
substituting target-specific values, and print them to stdout (one per line)
so they can be redirected to a file or piped into another tool.

Usage:
  ./gen-cmdexec.sh [category ...] [options]

Categories (default: all templates):
  reverse            reverse-shell connect-backs      (uses --ip [--port])
  touch              create a file                    (uses --file)
  cat                display a file                   (uses --file)
  all                every template

Options:
  -i, --ip IP        listener IP for reverse shells      (default: 127.0.0.1)
  -p, --port PORT    listener port for reverse shells   (default: 4444)
  -f, --file PATH    target file for touch / cat        (default: /tmp/coucou.txt)
  -s, --shell SH     shell for {SHELL} placeholders      (default: /bin/sh)
  -d, --dir DIR      templates directory      (default: <script dir>/cmdexec)
  -l, --list         list available categories (and payload counts) and exit
  -h, --help         show this help and exit

Each template in cmdexec/ is a category named after the file; add a new
*.txt there to add a category. Placeholders: {IP} {PORT} {FILE} {SHELL}.

Examples:
  ./gen-cmdexec.sh reverse --ip 10.10.14.7 --port 9001 > rev.txt
  ./gen-cmdexec.sh cat --file /etc/passwd
  ./gen-cmdexec.sh touch --file /var/www/html/poc.txt
  ./gen-cmdexec.sh all --ip 10.10.14.7 --file /etc/passwd
#+end_example
